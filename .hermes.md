# data-tidur-bps-halut — BANDA (Bangunin Data Tidur) — Konteks Proyek (untuk agen)

Stack: PHP 8.3 + Apache (web) | FastAPI Python 3.12+ (api) | MySQL/MariaDB (db).
Repo lokal: `C:\Users\TECNO\Desktop\Project\data-tidur-bps-halut`.

Run lokal (tanpa Docker):
- MariaDB portable di `.local-stack/` (di-gitignore), port 3306, db `db_data_tidur`, user `tidur_app`.
- FastAPI: `cd python-api && .venv/Scripts/python -m uvicorn main:app --port 8000` (venv terpasang).
- Web: `PHP_CLI_SERVER_WORKERS=4 php -S 127.0.0.1:8090 scripts/router-local.php` dari repo root.
- Env dari `.env` (source dulu: `set -a; . ./.env; set +a`).

Run Docker (butuh Docker Desktop — BELUM TERPASANG di mesin ini):
- `docker compose -f deploy/docker-compose.yml --env-file .env up -d --build` → web :8090.
